# 👶 母婴健康 AI 答疑助手

面向「渝欧·新物智 · 经营新星计划」面试准备的 Demo 项目。

一个面向**母婴 / 家庭健康私域社群**场景的 AI 答疑工具：把社群运营中重复、耗时的用户咨询，交给 AI 自动回答，让业务 owner 把精力放在选品、转化和建立用户信任上。

---

## 🎯 项目背景

- 岗位：AI 全域操盘手（业务 owner 方向）
- 公司业务五大板块：内容营销、电商运营、私域社群、线下门店、AI 工具基建
- 本项目对应：**私域社群 + 用户运营 + AI 工具基建**

核心价值：私域社群里用户最常问育儿 / 营养问题，人工客服无法 7×24 秒回，AI 可以，而且回答专业、带依据，帮助品牌建立长期信任、降低用户决策焦虑。

---

## ✨ 功能特性

- 💬 **AI 智能答疑**：接入大模型，回答任意育儿 / 营养问题，结尾附带实用小贴士
- 🔌 **AI 开关**：一键切换在线 / 离线，方便现场对比演示
- 📚 **内置知识库**：覆盖维生素D、钙、DHA、益生菌、奶粉五大高频问题
- ⚡ **快捷问题按钮**：一键点击即可演示，适合面试现场
- 🏷️ **AI 自动打标签**：在线时由大模型给每个问题自动分类（覆盖任意问题），离线回退关键词匹配
- 📊 **用户需求洞察看板**：把每次提问自动沉淀为数据，生成主题分布、高频问题榜（这是通用大模型做不到的，直接反哺选品与内容）
- 🧠 **AI 生成运营建议**：在线时把统计数据喂给大模型，自动产出内容 / 选品 / 社群三条建议；离线用规则兜底
- 💾 **数据持久化**：提问记录存入本地 SQLite（`insights.db`），重启 / 刷新不丢失，离线可用
- 🔐 **配置持久化**：AI 开关、服务商、地址、模型、Key 自动保存到 `config.json`
- 🧹 **清空对话 / 清空数据**：一键重置，清空数据带二次确认防误删

---

## 🤖 AI 在项目里的作用

AI 不止是"聊天"，它做三件事：

1. **答疑**：用大模型回答用户育儿 / 营养问题；
2. **打标签**：把每条用户提问自动归类，能处理任意问题、不只靠关键词；
3. **做经营判断**：读完用户提问数据，自动生成"该主推什么内容、备什么货、社群做什么动作"的运营建议。

> 也就是说，AI 在**读数据、辅助运营做决策**——这就是"驾驭 AI 的业务 owner"和"只会问豆包"的区别。

---

## 🆚 为什么不能直接问豆包 / DeepSeek

企业私域用通用大模型有四个解决不了的问题，本项目逐一对应用 AI 补齐：

| 差异点 | 直接问通用大模型 | 本项目 |
| --- | --- | --- |
| 私有知识 | 不知道你家产品、价格、活动 | 可接公司产品库 + 医生科普 |
| 合规可信 | 可能乱说医疗效果、出事不负责 | 带依据、答不了建议咨询医生 |
| 数据回流 | 你问了啥，老板看不到 | 提问沉淀成需求洞察，反哺选品 |
| 品牌信任 | 用户知道在跟第三方 AI 聊 | 品牌自有触点，信任沉淀在品牌 |

## 🛠 技术栈

| 模块 | 技术 |
| --- | --- |
| 前端 | Streamlit |
| 大模型 | DeepSeek 等（OpenAI 兼容接口，可换服务商） |
| 数据分析 | pandas（主题聚类、统计） |
| 数据存储 | SQLite（本地持久化，stdlib 内置） |
| 配置存储 | JSON（stdlib 内置） |
| 语言 | Python |

**依赖**：`streamlit`、`openai`（`pandas` 由 Streamlit 自带；`sqlite3`、`json` 为 Python 内置，无需安装）。

> 后续可扩展：接入公司产品资料 + 三甲医院医生科普内容，替换为真正的企业知识库（RAG）；封装进微信小程序。

## ⚙️ 使用说明

1. **AI 开关**：左侧「启用 AI 模式」一键切换在线 / 离线，方便现场对比演示
2. **服务商配置**：下拉选择服务商，自动带出默认 API 地址和模型，也可手动修改
3. **配置自动保存**：AI 开关、服务商、地址、模型、Key 会保存到本地 `config.json`，重启不丢
4. **在线模式**：填入 API Key（本地 Ollama 可不填），回答、打标签、运营建议均由大模型生成
5. **离线模式**：关闭 AI 开关，直接点击快捷问题按钮，走本地知识库兜底，数据仍会持久化
6. 点击快捷问题按钮，或在下方的输入框自由提问

### 支持的服务商

| 服务商 | API 地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-1-5-pro-32k-250115` |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 通义千问（阿里云） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen2.5` |

> 模型名以各服务商最新文档为准，可在界面手动修改。任何支持 OpenAI 兼容接口的模型都能接入。

## 🎬 面试演示流程（3 分钟）

1. 打开项目，先**关闭 AI 开关**（离线模式），点几个快捷问题，展示"本地知识库也能答"；
2. 点第 6 个快捷问题"宝宝六个月可以加什么辅食？"，展示**离线模式的局限**（答不上来、归类到"其他"）；
3. **打开 AI 开关**，再问同一个问题，展示 AI 能正确回答并打上"辅食"标签——**前后对比，AI 的价值就出来了**；
4. 切到"📊 用户洞察"页，展示主题分布、高频问题榜、AI 生成的运营建议；
5. 收尾一句话：*"AI 不只是聊天，它在读数据、辅助运营做决策。"*

## 🔧 如何扩展知识库

编辑 `app.py` 中的 `QA_KB` 列表，按以下格式添加条目即可：

```python
{"q": "关键词", "a": "回答内容"},
```

关键词用于离线兜底匹配，回答内容会同时作为大模型的参考知识。

## ⚠️ 安全提示

- `config.json` 中的 **API Key 为明文存储**（本地文件，不会上传）；
- 若要把整个项目打包发给他人，请先删除 `config.json` 中的 `api_key`，避免泄露。
